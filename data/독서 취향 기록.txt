독서 취향 기록

• 마지막 업데이트: 2026-09-04
• 용도: 이미 읽은 책과 감상, 작가 단위 취향, 밀리의 서재 미서비스 확인 내역을 누적해 다음 추천 때 중복과 헛추천을 줄이기 위한 기록.
• 업데이트 원칙: 사용자가 직접 읽었다고 밝힌 책/작가와 직접 남긴 평을 우선 기록. 대화상 번호로 완독이 확인된 경우에는 그 사실을 표시하고, 세부 평은 추정하지 않음.

취향 요약

• 캐릭터와 감정선이 매우 중요함. 추리·범죄 디테일 자체는 좋아하지만, 주인공에게 감정적으로 걸릴 이유가 없으면 몰입이 잘 안 됨.
• 플롯은 결말 한 방보다 도달 과정이 중요함. 중간 과정 자체가 재미있고, 인물의 욕망·상실·집착·관계 변화가 사건과 붙어 있을수록 선호.
• 반전은 신선하거나 앞부분을 납득되게 재해석시킬 때 선호. 단순히 마지막에 답을 교체하는 느낌, 억지로 영리한 척하는 느낌은 비선호.
• 범행방법·수사·추리 방식의 디테일은 좋아함. 다만 캐릭터가 퍼즐의 말처럼 기능하는 순수 본격추리에는 몰입이 약함.
• 속도감/페이지터닝을 좋아함. 여기에 유머나 개그감이 있으면 가산점.
• SF에서는 아이디어 + 철학/심리 + 관계의 감정적 여운을 선호. 특히 설정이 인간관계와 윤리 문제로 확장되는 작품을 좋아함.
• 밀리의 서재 서비스 작품 우선 추천. 외부 웹에 과거 밀리 페이지가 남아 있어도 현재 앱에서 안 보이면 미서비스로 간주.

• 간단 줄거리: 과거 참극이 있었던 외딴섬의 십각형 건물에 대학 미스터리 연구회 학생들이 모이고, 섬에서는 연쇄살인이 시작될 조짐이 나타난다. 동시에 본토에서는 과거 사건과 섬을 둘러싼 비밀을 조사하는 이야기가 병행된다. 작품의 핵심은 인물 정체와 두 공간을 이용한 서술 트릭 및 본격추리 구조.
• 사용자 평: 몰입이 안 되고 진도가 안 나감. 흥미 포인트가 없음. 캐릭터 감정선이 약해 인물들이 퍼즐의 말처럼 느껴짐. “이거 읽느니 내가 직접 방탈출 게임할 듯.” 이름을 이용한 서술 트릭도 다른 책에서 많이 봐서 새롭지 않았음.
• 취향 포인트: 순수 퍼즐/본격추리만으로는 부족. 인물에게 감정적으로 걸려야 함.

피에르 르메트르

《대문자 뱀》

• 상태: 완독
• 간단 줄거리: 나이 든 여성 킬러가 살인 의뢰를 수행하는 가운데 기억과 상황이 점점 꼬이고, 범죄와 실수가 연쇄되며 블랙유머와 스릴러가 결합된다.
• 사용자 평: 블랙유머와 설정은 괜찮았음. 감정선은 취향이 아니었지만 블랙코미디 스릴러로는 괜찮았음.
• 취향 포인트: 메인 취향은 아니어도 개성 있는 설정 + 블랙유머 + 속도감은 즐길 수 있음.

마이클 로보텀

《디 아더 와이프》

• 상태: 완독
• 간단 줄거리: 임상심리학자 조 올로클린의 아버지가 습격당하고, 병원에서 가족이 전혀 몰랐던 낯선 여성이 나타난다. 조는 아버지의 숨겨진 삶과 가족의 비밀, 습격 사건의 진실을 파헤친다.
• 사용자 평: 재밌게 봄. “속도감과 개그감이 괜찮더라.”
• 취향 포인트: 심리 / 가족관계 / 수사 / 주인공 감정선 / 속도감 / 유머

제시카 놀

《럭키스트 걸 얼라이브》

• 상태: 완독 + 영화도 봄
• 간단 줄거리: 성공적인 커리어와 완벽한 결혼을 앞둔 여성이 고등학교 시절의 폭력적이고 충격적인 사건과 다시 마주하며, 자신이 만들어온 이미지와 과거의 분노·상처를 직면한다.
• 사용자 평: “괜찮았던 듯.” 다만 내용은 잘 기억나지 않음. 영화도 봄.
• 취향 포인트: 불편한 주인공 / 트라우마 / 자기 이미지 / 분노

여러 작가

《굿 게임 굿 럭》

• 상태: 완독
• 간단 줄거리: 스포츠 에이전시의 고충처리팀을 공통 축으로 농구·축구·야구·테니스·바둑 등 각 종목의 선수와 관계자에게 벌어지는 사건을 여러 작가가 각각 풀어낸 연작형 미스터리 단편집.
• 사용자 평: “그냥 시간 때우기용으로 괜찮았음.” 강하게 남는 작품까지는 아니었음.

〈버저 비터〉 — 정해연

• 상태: 완독
• 간단 줄거리: 농구선수와 스포츠 업계의 문제를 고충처리팀이 다루며 사건의 진실을 추적하는 단편.
• 사용자 평: 별로. 결말이 너무 잘 보였고 신선하지 않았음. ‘버저 비터’라는 제목도 작품에 비해 **“있는 척, 허세 부리는 느낌”**이라 더 별로였음.
• 취향 포인트: 결말이 예상 가능하다는 사실 자체보다, 예상 가능한데 작품이 스스로 영리한 척하는 느낌을 특히 싫어함.

길리언 플린

여러 작품

• 상태: 여러 작품 읽음
• 간단 줄거리: 결함 많고 불편한 인물들의 욕망, 분노, 악의, 자기기만과 관계의 독성을 사건의 중심에 놓는 심리 스릴러가 주축.
• 사용자 평: “길리언 플린 책 좋아함.”
• 작가 평: 캐릭터가 먼저 살아 있고, 그 성격과 욕망 때문에 사건이 발생하는 작품을 좋아한다는 핵심 기준점.

정유정

여러 작품

• 상태: 다수 읽음
• 간단 줄거리: 범죄·폭력·극한 상황에서 인물의 욕망과 본능, 죄책감, 집착을 강한 서사와 함께 밀어붙이는 장편들이 중심.
• 사용자 평: “정유정 건 다 좋게 봄.”
• 작가 평: 강한 캐릭터 + 감정선 + 추진력 있는 플롯을 동시에 선호한다는 중요한 기준점.

찬호께이

여러 소설

• 상태: 다수 읽음
• 간단 줄거리: 범죄와 추리를 치밀하게 설계하면서도 홍콩 사회의 구조, 기술, 시대 변화, 인간관계와 감정을 사건 안에 함께 녹여내는 작품들이 중심.
• 사용자 평: “찬호께이들 소설들도 다 재밌게 봄.”
• 작가 평: 범행·추리 디테일과 플롯 구조뿐 아니라 캐릭터 감정선과 사회적 맥락이 함께 살아 있는 범죄소설을 좋아한다는 핵심 단서.

다음 추천 시 필터

1. 밀리의 서재에서 실제 현재 서비스되는 작품 우선. 가능하면 사용자의 앱 검색 결과를 최종 기준으로 사용.
2. 이미 읽은 책/작가 반복 추천 금지.
3. 캐릭터의 감정선이 약하고 퍼즐만 남는 본격추리는 우선순위 낮춤.
4. 수사·범행 디테일은 적극 허용. 단, 주인공 개인 서사와 감정적 동력이 같이 있어야 함.
5. 심리 스릴러는 결말 반전보다 중간 과정의 긴장과 캐릭터 변화를 우선 평가.
6. ‘영리한 척’하는 억지 반전/서술 트릭보다 실제로 앞뒤가 맞고 인물 심리와 연결되는 설계를 선호.
7. 속도감과 유머/개그감은 가산점.
8. SF 추천 시: 아이디어 + 철학/심리 + 관계의 여운을 우선. 《해리 오거스트》의 애증적 우정, 《앨저넌에게 꽃을》의 심리학/씁쓸한 여운, 테드 창의 사변적 아이디어를 기준점으로 삼기.
