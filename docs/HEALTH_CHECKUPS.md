# 건강검진 기록 가져오기

건강검진 수치는 **민감한 개인 의료정보**입니다. 이 앱은 그 파일을 저장소에도, 배포되는 사이트 파일에도 넣지 않습니다.

## 어떻게 동작하나

1. 건강 탭 아래 **건강검진 수치**에서 결과 JSON 파일을 고릅니다.
2. 파일은 **브라우저 안에서만** 읽힙니다. 어떤 서버로도 업로드되지 않습니다.
3. 읽은 수치는 로그인한 **내 계정의 개인 공간**(`users/{내UID}/checkups`)에만 저장됩니다.
4. 다른 계정은 서버 규칙에 의해 이 경로를 읽을 수 없습니다.

원본 파일 자체는 앱이 보관하지 않습니다. 파일은 개인 기기에 두세요. **`docs/` 폴더에는 두지 마세요 — 이 폴더는 GitHub Pages로 그대로 공개됩니다.** `.gitignore`가 `docs/health_checkups*.json`을 막고 있지만, 파일명이 다르면 걸리지 않습니다.

## 저장되는 내용

한 건은 검진 구분과 검진일로 구분됩니다(`general_2023-12-27`). 같은 파일을 다시 불러와도 **덮어쓰기만 하고 중복 기록이 생기지 않습니다.**

보관하는 항목: 키, 체중, 체질량지수, 허리둘레, 수축기·이완기 혈압, 혈색소, 공복혈당, 총콜레스테롤, HDL·LDL 콜레스테롤, 중성지방, 혈청 크레아티닌, 신사구체여과율, AST, ALT, 감마지티피, 좌·우 시력.

## 그래프

일반건강검진 기록이 2회 이상 있는 지표는 **연도.월** 눈금의 꺾은선 그래프로 볼 수 있습니다. 지표 선택 상자에는 **실제로 값이 있는 항목만** 나옵니다.

- 결과가 없는 회차는 **선을 잇지 않습니다.** 중간값을 만들어 채우지 않습니다.
- 한 번만 기록된 지표는 흐름 대신 그 값 하나만 보여 줍니다.
- 세로축은 기록된 값의 범위에 맞춰 그려집니다. **정상 범위를 뜻하지 않습니다.**

## 앱이 하지 않는 것

- **정상·이상을 판정하지 않습니다.** 검진표에 적힌 판정을 그대로 보여줄 뿐, 앱이 새로 해석하지 않습니다.
- **없는 값을 0으로 세지 않습니다.** 검사하지 않은 항목은 `—`로 두고, 몇 개가 비었는지 함께 알려 줍니다. 비어 있음은 정상도, 음성도 아닙니다.
- **이 수치로 식사 목표나 감량 목표를 자동으로 정하지 않습니다.** 기초대사량 추정값이 파일에 있어도 섭취 목표로 쓰지 않습니다.
- **의료 진단·상담을 제공하지 않습니다.** 수치 해석은 의료기관에서 받으세요.

## 서버 규칙

`firestore.rules`에 `users/{uid}/checkups/{id}` 규칙이 있어야 저장됩니다. 규칙을 갱신한 뒤 **Firebase Console에 다시 게시**해야 합니다. 게시 전에는 저장 시 권한 오류가 납니다.
